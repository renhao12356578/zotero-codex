# Zotero Codex MCP v0.5.1

用 Zotero 的区域批注工具框选 PDF 后，MCP 自动获取区域截图、页码和来源，无需再拖入侧栏。截图准备好后，可以直接让 Codex 解释刚框选的图。

- 监听 Reader 新建区域批注，等待实际截图缓存，最多等待约 10 秒；不阻塞 Zotero 的批注保存通知。
- 按 Reader 分开保存快照；新区域或文字选择覆盖旧快照，异步读取也不会返回被替换的区域。
- 后台同步和导入的批注不覆盖上下文。已有批注仍可手动拖入。
- 不自动发送消息或触发 AI 回答。

验证：37 项自动化测试通过；Zotero 10.0.3 的真实 Reader 批注创建、保存、PDF 区域渲染、自动捕获 5 项检查通过；标准 MCP stdio 返回实际 PNG 图片和来源的 3 项检查通过。宿主使用隔离文库与公开 PDF 样本，由程序调用 Reader 批注创建接口，未做实际鼠标手势验收。

同时更新 XPI 与 Node 服务到 0.5.1。原有 MCP 配置及工具数量不变；安装步骤见 `docs/local-setup.md`。
