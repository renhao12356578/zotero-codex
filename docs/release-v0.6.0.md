# Zotero Codex MCP v0.6.0

新增 Zotero 原生设置页，在「设置 → Zotero MCP」统一管理连接和阅读上下文。阅读侧栏也有快捷入口。

- 查看桥接服务、Zotero 本地 API、Better Notes、最近访问插件的时间和 MCP 服务版本；不把服务启动显示成 Codex 在线。
- 文字选区、区域截图分别设置自动捕获，默认开启、立即生效、持久保存。关闭会清除对应的自动快照；手动添加和拖入批注仍可用。
- 一键清除所有阅读器的 MCP 快照及待生成截图，不删除批注或笔记。
- 识别 Node 服务路径、复制通用 MCP JSON 配置、打开连接文件所在目录，以及查看安装说明和版本。
- 本机连接诊断可报告 API 被关闭等问题；复制报告不含令牌、绝对路径或文献笔记内容。自检不会被计作客户端访问。

验证：40 项自动化测试、14 项真实 Zotero 10.0.3 设置页检查、4 项真实 MCP stdio 检查通过；800 × 600 原生窗口排版已检查。测试使用隔离文库，程序触发真实 DOM 控件与 Reader 事件。

安装新 XPI，并更新同版本源码后重新加载 MCP。工具数量仍为 43 个。配置页不会自动改写 Codex 配置，复制的 JSON 用于支持 mcpServers 格式的客户端；Codex CLI 设置方法见安装指南。
