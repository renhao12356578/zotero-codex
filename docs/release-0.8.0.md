# 0.8.0 — 优先复用已有 Node.js

- 自动检测 PATH、Homebrew、标准安装目录与常见版本管理器中的 Node；不执行 shell 配置，不修改系统 Node 或 PATH。
- 本机 Node 满足版本、架构及服务/PDF 依赖检查后，只下载更小的服务包，避免重复下载 Node。
- 找不到兼容 Node 或实际服务检查失败时，自动复用已安装的专用 Node，或下载完整运行包。
- 设置显示 Node 来源和版本，可关闭“优先复用本机 Node.js”改用专用环境。
- 系统 Node 与专用 Node 切换时，托管 Codex 配置自动更新，其他配置与工具权限保持不变。

支持 Node 22.13+（22.x）或 24 及以上稳定版本。系统 Node 后续发生变化时，在 Zotero 启动、手动准备或连接时重新检查并回退；配置变化后重启 Codex。

普通用户仍只需安装 XPI，等待准备完成，再点击连接 Codex。
